🎯 Overview
Project Goal
Transform the HomeIQ mobile app from a professional black/white theme to BrandSmart USA's bold retail brand identity with deep blue primary color and energetic red accents.

Brand Identity
Primary Color: Deep Blue #0057A0 (HSL: 207° 100% 31%)
Accent Color: Bold Red #E31837 (HSL: 351° 78% 49%)
Style: Bold, retail-focused, high-energy, trust-building
Button Style: Rectangular with slight rounding (borderRadius: 4-6)
Scope
This guide covers ALL screens, components, and interactions in the mobile app, organized by feature area for systematic implementation.

Color Usage Guidelines
Use Case	Color	Example
Primary buttons	primary + white text	Book Service, Submit, Confirm
Button pressed state	primaryDark	Touch feedback
Selected items	primary10 background + primary border	Selected cards, active tabs
Icon highlights	primary	Active icons, feature icons
Links/clickable text	primary	"View Details", "Learn More"
Focus indicators	primary50 border	Input focus, keyboard navigation
Hover/touch areas	primary05 background	Card hover, button hover
Alerts/badges	accent (red)	Notifications, urgent items
Pricing/emphasis	primary	Price tags, important values
